# components/

UI pieces used by the screens in `app/`. Plain React Native (works on web through react-native-web). Colours, fonts and sizes come from `lib/theme/theme.ts`. No images, no stock prices.

## Subfolders

| Folder | Holds |
| ------ | ----- |
| `account/` | Sign-up and sign-in forms, password field, brief sign-up management |
| `brief/` | Brief chrome, stories and summary |
| `card/` | Feed card, card actions and menu, data card, detail sheet, source list and chips, labels, card footer, trend chart |
| `companies/` | "About: <company>" chips on cards, a company row with Follow, and the company rows for the top of Search |
| `feed/` | Feed pager, category chips, sort toggle, topic pickers, For you warm-up, undo toast |
| `following/` | Followed stories, follow button and pill, following feed, manager and watchlist |
| `numbers/` | Numbers panel and ticker, brief numbers and markets |
| `search/` | Search box, idle state, result card and results list |
| `shell/` | App shell, screen shell, tab bar, wide aside, states, sample banner, error boundary, icons |
| `tutorial/` | Tutorial overlay, motion, parts and practice card |

Wide cards (`wide`): 48 px headline, 21 px takeaways, and a "tight" mode (card under 660 px tall) that shrinks padding and type so the bar always fits. Phones: 18 px takeaways on tall cards, 16 px on compact (short) screens; the bar switches to the `small` size under 350 px of card width. Save / Report buttons from the design are not built.

Rules kept here: every card has a source link in its bar; like and dislike on every card (D-63); the AI notice and the disclaimer appear once per feed-style screen in `FeedNotice` (D-80) and inside standalone views (detail sheet, sources sheet); direction is never shown by colour alone; every source links to the original URL.

Accessibility note: react-native-web ignores `accessibilityState` and `accessibilityHint`, so selected or pressed states use `aria-selected`, `aria-checked`, `aria-pressed` and `aria-disabled`, and hints are part of the label.
